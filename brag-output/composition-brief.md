# DNA Detective — Brag plan

1. Product: a reproducible botanical-authentication research prototype.
2. Strongest finding: the noise floor changes detection sensitivity in simulation.
3. Hook: “Is your spice what it claims?” with a botanical DNA illustration.
4. Actual material: the seeded sample S06 verdict and the generated detection figure.
5. Duration: 24 seconds, landscape 1920 × 1080.
6. Tone: polished; a botanical research journal brought into motion.
7. Audio: an original, locally synthesized soft arpeggio with sparse warm accents; no narration.
8. Share copy: “DNA Detective explores how noise filtering changes botanical authentication. Reproducible simulations, explicit thresholds, and honest limits.”
9. Flow: species counts → noise filtering → label comparison → an inspectable verdict. This is an animated explanation, not a claimed web UI.

## Visual identity
The repository has no website design. Use forest #10251F, paper #F2EEDC, chartreuse #D9E98B, muted sage #B4C6B9. Cormorant Garamond headings; Manrope body. Fine specimen lines and huge editorial headings. Keep simulation status visible. No invented sequencing results.

## Storyboard
- 0–5s / Question: headline unfolds alongside an illustrated DNA motif. Hold the question; then a quick lateral exit. Small “BOTANICAL AUTHENTICATION” label.
- 5–11s / Method: actual sample S06 from the simulated panel. Counts → noise floor → verdict appear sequentially; enough time to read the full result. State “SIMULATED INPUT”.
- 11–18s / Evidence: actual limit-of-detection figure fills the right side. Left-side takeaway: “The threshold changes what you detect.” One concise pair of read fractions, sourced from the output CSV.
- 18–24s / Closing: DNA Detective title, “Reproducible. Inspectable. Open.” Repository link and “Simulation validated · Real-data validation pending”. No claim of real product detection.
